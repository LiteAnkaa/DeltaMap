DeltaMap v1.5 — финальная онлайн-версия для Vercel

ЧТО ВНУТРИ
- Онлайн-карта Украины с подписями областей.
- Боковая панель управления. На публичной странице она полностью скрыта; кнопки открытия нет.
- Админ-панель открывается по адресу: https://ВАШ-ДОМЕН.vercel.app/?admin=1
- Общие статусы для всех посетителей через API /api/status.
- Кнопки: красный/желтый информационный уровень, радиационная/химическая информационная отметка, сообщение о столкновениях, отмена статуса.

РАЗВЕРТЫВАНИЕ
1. Распакуйте архив.
2. Загрузите ВСЕ файлы и папку api в корень GitHub-репозитория.
3. Импортируйте репозиторий в Vercel и выполните Deploy.
4. В Vercel откройте Storage/Marketplace и создайте Upstash Redis.
5. В Project Settings -> Environment Variables добавьте:
   DELTAMAP_ADMIN_PASSWORD = длинный уникальный пароль администратора
   KV_REST_API_URL = REST URL базы Upstash
   KV_REST_API_TOKEN = REST token базы Upstash
   Если интеграция создала UPSTASH_REDIS_REST_URL и UPSTASH_REDIS_REST_TOKEN, код поддерживает и эти имена.
6. Сохраните переменные и сделайте Redeploy.
7. Обычная карта: https://ВАШ-ДОМЕН.vercel.app/
   Панель администратора: https://ВАШ-ДОМЕН.vercel.app/?admin=1 (открывается напрямую по ссылке)
8. Введите DELTAMAP_ADMIN_PASSWORD в поле пароля. GET /api/status открыт для чтения статусов, POST защищён паролем.

ВАЖНО
- Без Redis и переменных окружения общая публикация не заработает.
- Не отправляйте пароль или токены в чат и не вставляйте их в index.html.
- Все статусы здесь являются пользовательскими информационными отметками DeltaMap. Они не являются официальными оповещениями, сигналами сирены или подтверждением безопасности. Не публикуйте неподтверждённые сведения.
- Для официальной информации пользователи должны ориентироваться на государственные источники и местные органы власти.
